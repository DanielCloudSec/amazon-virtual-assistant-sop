# SOP: Product Listing for Amazon

## Goal
To create optimized Amazon listings with accurate descriptions, pricing, and SEO keywords.

## Steps
1. Use the product research sheet to find top 3 competitors
2. Find top competitor products, then
2. Input products into Python script to find similar products for futher evaluation
3. Analyze sales rank, titles, bullet points, and price points
4. Write draft listing in Google Doc
5. Submit for review in Slack with subject: `Listing Draft - [Product Name]`
6. After approval, copy into Amazon Seller Central and publish

## Notes
- Use keyword tool Helium10 
- Keep tone professional and benefit-focused
- Use Jungle Scout to evaluate sales rank
